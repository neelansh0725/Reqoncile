# Reqoncile — deployment dependencies (see docs/deployment.md)
#
# Differs from requirements.txt in exactly two ways, both forced by a 512MB
# free-tier container:
#
#   1. No sentence-transformers / torch. The ONNX backend serves the SAME
#      all-MiniLM-L6-v2 weights through onnxruntime, which chromadb already
#      depends on. Measured: identical vectors (cosine 1.0000), identical
#      retrieval rankings and scores. 602MB peak RSS -> 285MB.
#   2. No Ollama, no test tooling. Generation runs on the hosted tier.
#
# Requires REQONCILE_EMBEDDING_BACKEND=onnx. With this file installed and the
# backend left as 'torch', startup logs an EmbeddingError and /health reports
# the model as unavailable -- deliberately non-fatal so an operator can still
# reach /health to see why, rather than facing a container that will not boot.
